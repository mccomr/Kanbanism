# Monochrome Board

A SwiftUI Kanban app for iPhone and iPad. Create projects with one of six soft pastel colors, add or rename columns, and create tasks with optional details. Every task card uses its project's color. Edit a project's color to update all of its tasks at once. Move tasks by dragging cards between columns, choosing a destination in the task editor, or using a card's context menu. Boards save locally on the device.

Open [MonochromeBoard.xcodeproj](MonochromeBoard.xcodeproj) in Xcode 16 or newer and run the `MonochromeBoard` scheme on an iOS 17 or newer simulator or device. For a physical device, select your development team and set a unique bundle identifier in the target's Signing & Capabilities settings.
