# Monochrome Board

A SwiftUI Kanban app for iPhone and iPad. Each board starts with an Opportunity Leads column. Choose from 15 bright colors for every opportunity, then link tasks in the remaining columns to an opportunity so they inherit its color automatically. Curved, color-matched connectors show each opportunity's relationship to its tasks and reposition as cards move. Every column can use a soft tinted background or remain charcoal. Add, edit, and reorder workflow columns by dragging their headers or using Move left and Move right in the column menu. Move tasks by dragging cards between workflow columns, choosing a destination in the task editor, or using a card's context menu. Boards save locally on the device.

Open [MonochromeBoard.xcodeproj](MonochromeBoard.xcodeproj) in Xcode 16 or newer and run the `MonochromeBoard` scheme on an iOS 17 or newer simulator or device. For a physical device, select your development team and set a unique bundle identifier in the target's Signing & Capabilities settings.
