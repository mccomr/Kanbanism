# Kanbanetti

A SwiftUI Kanban app for iPhone and iPad. Each board starts with an Opportunity Leads column. Choose from 15 bright colors for every opportunity, then link tasks in the remaining columns to an opportunity so they inherit its color automatically. Opportunity cards automatically form a sticky stack at the top as their column scrolls. Tap an opportunity to keep it and its tasks bright while unrelated cards and connectors fade to 25% brightness. Curved, color-matched connectors show each opportunity's relationship to its tasks and reposition as cards move. Every column has its own vertical card scroller, can use a soft tinted background or remain charcoal, and can switch between a full task list and a compact stacked deck. Add, edit, and reorder workflow columns by dragging their headers or using Move left and Move right in the column menu. Reorder tasks within a column by dragging one card onto another or using Move up and Move down. Move tasks between workflow columns by dragging, choosing a destination in the task editor, or using a card's context menu. Boards save locally on the device.

Open [MonochromeBoard.xcodeproj](MonochromeBoard.xcodeproj) in Xcode 16 or newer and run the `Kanbanetti` scheme on an iOS 17 or newer simulator or device. The distribution bundle identifier is `com.kanbanetti.app`; register it to the selected development team before archiving.

The same scheme supports Mac Catalyst. Select **My Mac (Mac Catalyst)** in Xcode to build and run `Kanbanetti.app` on macOS. App Store copy, privacy details, export settings, and the submission checklist are in the `AppStore` folder.
