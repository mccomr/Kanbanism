# Monochrome Board

A SwiftUI Kanban app for iPhone and iPad. Create projects with one of six soft pastel colors, add or rename columns, and create tasks with optional details. Tasks inherit their board's color by default, and each task can also have its own pastel color. Reorder columns by dragging their headers or using Move left and Move right in the column menu. Move tasks by dragging cards between columns, choosing a destination in the task editor, or using a card's context menu. Boards save locally on the device.

Open [MonochromeBoard.xcodeproj](MonochromeBoard.xcodeproj) in Xcode 16 or newer and run the `MonochromeBoard` scheme on an iOS 17 or newer simulator or device. For a physical device, select your development team and set a unique bundle identifier in the target's Signing & Capabilities settings.
